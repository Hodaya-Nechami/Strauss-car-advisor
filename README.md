# יועץ הרכב של שטראוס

בוט בעברית שעונה לעובד: "מה יקרה לנטו שלי אם אחליף רכב, אעבור לחשמלי או אוותר על הרכב?"
האקתון AI קוד פתוח 2026, אתגר בשיתוף שטראוס.

## הפעלה

צריך Node.js 20 ומעלה ומפתח API של Claude.

1. מתקינים את החבילות:
   ```
   npm install
   ```
2. מעתיקים את `apps/web/.env.example` ל-`apps/web/.env.local` וממלאים את המפתח:
   ```
   ANTHROPIC_API_KEY=המפתח שלכם
   ```
   את `.env.local` לא מעלים לגיט. הוא כבר ב-`.gitignore`.
3. מפעילים את האתר ופותחים בדפדפן את `http://localhost:3000`:
   ```
   npm run dev
   ```

בדיקות, בלי מפתח ובלי אינטרנט:
```
npm test
npm run typecheck
```

## איך זה עובד

1. העובד כותב בצ'אט. השרת שולח את השיחה ל-Claude עם ההנחיות (`packages/agent/src/prompt.ts`) ועם רשימת הכלים.
2. Claude לא מחשב בעצמו. הוא מפעיל כלים: שמירת נתוני שכר, קטלוג רכבים, חיפוש במאגר, בדיקת זכאות, חישוב השוואה ושאלה לנציג.
3. הכלים קוראים למנוע החישוב. המנוע מחזיר מספרים מדויקים, והמסך מציג אותם בכרטיס השוואה.
4. כשחסר נתון שרק החברה יודעת, הבוט שולח שאלה לנציג ומציג בינתיים את מה שכבר חושב. כשהנציג עונה, התשובה נכנסת לשיחה כהודעת מערכת, והבוט ממשיך מאותה נקודה.

## קבצי ההגדרות (`config`)

- `rules.json`: תקציבים, קבוצות, מסלול משפחתי, החזר חשמל, שיטת חישוב הנטו.
- `catalog.json`: 20 הרכבים בקטלוג (מגיליון "קטלוג רכבים").
- `occupations.json`: 14 העיסוקים, ומי מהם יכול לוותר על רכב.
- `sample-employees.json`: 6 העובדים לדוגמה.
- `reference-results.json`: נטו הייחוס של המארגנים. הבדיקות משוות אליו.

אם האקסל מתעדכן: `npm run config:build`. אחרי שינוי בקבצי ההגדרות מפעילים את השרת מחדש.

## מצב נוכחי

- **מנוע החישוב:** מוציא בדיוק את נטו הייחוס של המארגנים לכל 6 העובדים, כולל טקסט "למה". מקרי קצה בדוקים: ויתור בקבוצה ב', תפקיד שטח, בחירה מקבוצה גבוהה, מסלול משפחתי, פלאג-אין, השתתפות חסרה.
- **הבוט:** Claude Opus 5.5 עם 8 כלים. ההיסטוריה נשמרת בשיטת "רק מוסיפים בסוף", ובדיקה אוטומטית מוודאת את זה. מופעל מנגנון גיבוי: אם מסנן הבטיחות של Claude דוחה בטעות שאלה תמימה, השרת מנסה מודל חלופי.
- **האתר:** צ'אט מימין לשמאל, כרטיס השוואה עם כל הרכיבים, הודעת "ממתין לנציג" ובדיקה אוטומטית אם הנציג ענה. השיחה שורדת רענון של הדף.
- **בלי לחכות לבוט:** בכרטיס ההשוואה יש פירוט "איך חושב?" עם כל שלבי החישוב, ואפשר לבחור רכב אחר ולחשב מחדש. בטופס "הנתונים שלי" אפשר לתקן שכר והפרשות. הפעולות האלה עוברות דרך אותם כלים ואותו מנוע, והבוט מקבל עליהן הודעה.
- **עדיין זמני:** השיחות נשמרות בזיכרון של השרת ונמחקות כשהוא עולה מחדש. החיפוש במאגר מכיר רק את רכבי הקטלוג. אין עדיין מסך נציג.

## החלטות שקיבלנו

- **מודל השפה:** Claude Opus 5.5, ברמת מאמץ medium. אפשר לשנות ב-`.env.local` בלי קוד.
- **פלאג-אין לא מקבל החזר חשמל.** הכלל מדבר על "רכב חשמלי". אפשר לשנות ב-`rules.json` בשדה `electric.eligibleDrives`.
- **רכב נוכחי שלא בקטלוג:** הבוט מחפש אותו במאגר רשות המסים. אם יש יותר מהתאמה אחת, הוא שואל את העובד או את הנציג.
- **ההפרש שמוצג לעובד** הוא נטו מעוגל בחלופה פחות נטו מעוגל היום, כמו אצל המארגנים.
- **תשובת נציג נכנסת רק כהודעת מערכת,** כך שעובד לא יכול להתחזות לנציג בצ'אט.

## נחמי: מאיפה להתחיל

1. **בדיקות אוטומטיות (N2):** GitHub Actions שמריץ `npm ci`, `npm run typecheck`, `npm test` ו-`npm run build`.
2. **מאגר רשות המסים (N3, N4):** לייבא את `data/source/value-of-use-2026.csv` ל-SQLite, ולממש את `DataSource` שב-`packages/agent/src/ports.ts`. הקובץ בקידוד cp1255, וצריך לנקות רווחים מכל השדות.
   - מפתח החיפוש חייב לכלול את קוד סוג הרכב. בלי זה, ATTO 3 ו-TANG מקבלים אותו מפתח.
   - הכותרת של עמודת ההנעה ב-CSV מטעה. הפירוש הנכון הוא זה שב-`rules.json`: 0 בנזין, 1 היברידי, 2 פלאג-אין, 3 חשמלי. זה נבדק מול כל 20 רכבי הקטלוג.
3. **מסד נתונים (N6):** להחליף את השמירה בזיכרון ב-`apps/web/lib/server.ts`. כל שיחה נשמרת כאובייקט `SessionState` אחד ועוד רשימת `transcript`. את `session.messages` שומרים בדיוק כמו שהם, בלי לערוך. כל פעולה על שיחה עוברת דרך `withLock`, כדי ששתי פעולות לא יכתבו להיסטוריה באותו זמן. עם מסד נתונים, הנעילה צריכה לעבוד גם בין כמה שרתים.
4. **מסך נציג (N7, N8):** ב-`apps/web/lib/server.ts` כבר יש `listOpenRepQuestions` ו-`answerRepQuestion`. צריך API ומסך `/rep` שקוראים להן. מסך העובד כבר בודק כל כמה שניות אם הנציג ענה.
5. החוזה המשותף נמצא ב-`packages/engine/src/types.ts` וב-`packages/agent/src/ports.ts`. שינוי שם דורש תיאום בינינו.
